Task-based recipes: "how do I do X with Vormen?" — one concept per page, each
with the code inline in a `vorm` block (rendered to the SVG you see below it)
and a download link for the source. Adapt a recipe to your own project. For
visually appealing finished pieces, see the [Gallery](/examples).
