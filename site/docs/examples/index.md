The [`examples/` directory](https://github.com/berkes/vormen/tree/main/examples)
contains runnable example drawings. Each example below has its own page showing
the source code and the rendered SVG output(s).

All example SVGs are generated and committed, and are regenerated as part of
this site's build (`npm run build` in `site/` runs the generation first), so
these pages can never show stale artwork. To regenerate them by hand:

```bash
just generate-examples
```
