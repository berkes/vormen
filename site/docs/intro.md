_Vormen_ is a bag of tools, modules and scripts for creating generative art in
SVG using Javascript.

## Who is this for?

- **You design in the browser, and now want to make art with code.** Start with
  the [Quickstart](/quickstart) (one drawing in five minutes), get inspired in
  the [Gallery](/examples), then adapt a [Cookbook](/cookbook) recipe — every
  recipe can be downloaded and run as-is.
- **You're a developer looking for tools to create visuals through code.** Browse
  the [API reference](/modules) module by module, see
  [pick-and-choose](/pick-and-choose) usage (import only what you need), and use
  the runner to turn any drawing into a CLI or a web app.

## Features

- Classes, functions and modules used in your code to easily create artwork in
  SVG.
- An optional runner module that turns your drawing into a program: render it to
  an SVG file, or serve it in a browser with a settings UI.
- Tools to run your code in a browser and interact with the SVG there
